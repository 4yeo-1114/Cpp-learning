# C++ 算法学习仓库

这是我的 C++ 算法与数据结构学习笔记，涵盖 LeetCode 风格题目和课堂作业练习。

## 目录结构

```
.
├── array/             数组操作（最大子数组、轮转、缺失正数、除自身外乘积）
├── binary/            二分查找（lower_bound、旋转数组搜索、二维搜索、中位数）
├── dp/                动态规划（背包、LIS、爬楼梯、打家劫舍、单词拆分、接雨水）
├── greedy/            贪心算法（删数问题、分糖果、合并果子、任务调度）
├── hash/              哈希表（两数之和、字母异位词分组、最长连续序列、无重复子串）
├── double index/      双指针（盛水最多容器、三数之和）
├── slide window/      滑动窗口（最小覆盖子串、最短子数组）
├── sort/              排序算法（经典排序汇总、快速排序、希尔排序）
├── List/              链表（反转、K个一组反转、合并K个、LRU缓存、排序链表）
├── Tree/              二叉树（遍历、深度、BST验证、最近公共祖先、最大路径和）
├── graph/             图论（岛屿数量、课程表、腐烂橘子）
├── matrix/            矩阵操作（螺旋遍历、旋转、置零）
├── divide and conquer/   分治（残缺棋盘）
└── study/             C++ 课堂练习
    ├── Class/         类特性练习（虚函数、友元、运算符重载、拷贝控制）
    ├── ptr/           智能指针（unique_ptr / shared_ptr）
    ├── template/      模板练习
    └── test/          考试/测验代码
```

## 技术环境

| 项目 | 说明 |
|---|---|
| 语言 | C++23 |
| 编译器 | MSVC (`cl.exe`)，x64 |
| 编译命令 | `cl.exe /std:c++23 /EHsc <file>.cpp` |
| 平台 | Windows 11 |

每个 `.cpp` 文件独立编译运行，无构建系统依赖。
